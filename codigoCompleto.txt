Archivo: cargaBaseDatos.bat
Ruta: Codigo_Funcional\BDpizzeria\cargaBaseDatos.bat
Descripcion: Script batch para adjuntar/cargar la base PizzeriaDB en LocalDB usando cargaBaseDatos.sql.
Contenido:
	@echo off
	chcp 65001 >nul
	setlocal
	
	title Cargar base de datos - Pizzeria Bella Italia
	
	cd /d "%~dp0"
	
	set "SERVIDOR=(localdb)\MSSQLLocalDB"
	set "SCRIPT=cargaBaseDatos.sql"
	set "CADENA=Server=(localdb)\MSSQLLocalDB;Database=PizzeriaDB;Integrated Security=True;"
	
	echo ============================================================
	echo  CARGA / CONEXION DE LA BASE DE DATOS - PIZZERIA BELLA ITALIA
	echo ============================================================
	echo  Servidor : %SERVIDOR%
	echo  Script   : %SCRIPT%
	echo  Carpeta  : %~dp0
	echo ============================================================
	echo.
	
	if not exist "%SCRIPT%" (
	    echo [ERROR] No se encontro el script "%SCRIPT%" en esta carpeta.
	    goto :error
	)
	
	if not exist "%~dp0pizzeriaDB.mdf" (
	    echo [ERROR] No se encontro "pizzeriaDB.mdf" en esta carpeta.
	    echo         Ejecute primero creaBaseDatosP.bat para crear la base.
	    goto :error
	)
	
	where sqlcmd >nul 2>&1
	if errorlevel 1 (
	    set "SQLCMD=C:\Program Files\Microsoft SQL Server\Client SDK\ODBC\170\Tools\Binn\SQLCMD.EXE"
	    if not exist "%SQLCMD%" (
	        echo [ERROR] No se encontro sqlcmd en el PATH ni en la ruta habitual.
	        echo         Instale las herramientas de linea de comandos de SQL Server
	        echo         o ejecute el script manualmente desde SQL Server Management Studio.
	        goto :error
	    )
	) else (
	    set "SQLCMD=sqlcmd"
	)
	
	echo Cargando la base de datos en la instancia LocalDB...
	echo.
	"%SQLCMD%" -S "%SERVIDOR%" -E -b -i "%SCRIPT%"
	if errorlevel 1 goto :error
	
	echo.
	echo ============================================================
	echo  BASE DE DATOS CONECTADA CORRECTAMENTE
	echo ============================================================
	echo  Cadena de conexion que usa la aplicacion:
	echo  %CADENA%
	echo ============================================================
	pause
	exit /b 0
	
	:error
	echo.
	echo ============================================================
	echo  ERROR: no se pudo cargar/conectar la base de datos.
	echo  Revise los mensajes anteriores.
	echo ============================================================
	pause
	exit /b 1
	
Archivo: cargaBaseDatos.sql
Ruta: Codigo_Funcional\BDpizzeria\cargaBaseDatos.sql
Descripcion: Script SQL que adjunta pizzeriaDB.mdf/ldf a LocalDB (o reconstruye log) y verifica la base/tabla.
Contenido:
	-- ============================================================================
	-- CARGA / CONEXIÓN DE LA BASE DE DATOS - PIZZERÍA BELLA ITALIA
	-- ----------------------------------------------------------------------------
	-- Motor    : SQL Server / LocalDB
	-- Servidor : (localdb)\MSSQLLocalDB
	-- Base     : PizzeriaDB
	-- Archivos : pizzeriaDB.mdf y pizzeriaDB.ldf en esta misma carpeta
	--
	-- Este script NO crea la base desde cero: adjunta (attaches) los archivos
	-- existentes a la instancia de LocalDB, para que la aplicación pueda conectarse
	-- con su cadena de conexión:
	--
	--   Server=(localdb)\MSSQLLocalDB;Database=PizzeriaDB;Integrated Security=True;
	--
	-- Uso:
	--   - Si la base ya está conectada, solo verifica su estado.
	--   - Si no está conectada, la adjunta desde esta carpeta.
	--   - Si los archivos no existen, indica ejecutar creaBaseDatosP.bat.
	-- ============================================================================
	
	SET NOCOUNT ON;
	
	DECLARE @DataDir NVARCHAR(400) = N'C:\desarrollo\Csoft\App_WinForms_Pizzeria_Bella_Italia_BD\Codigo_Funcional\BDpizzeria';
	DECLARE @Mdf     NVARCHAR(500) = @DataDir + N'\pizzeriaDB.mdf';
	DECLARE @Ldf     NVARCHAR(500) = @DataDir + N'\pizzeriaDB.ldf';
	
	DECLARE @ExisteMdf INT = 0;
	DECLARE @ExisteLdf INT = 0;
	EXEC master.dbo.xp_fileexist @Mdf, @ExisteMdf OUTPUT;
	EXEC master.dbo.xp_fileexist @Ldf, @ExisteLdf OUTPUT;
	
	-- ----------------------------------------------------------------------------
	-- 1) Si la base ya está conectada, no se hace nada
	-- ----------------------------------------------------------------------------
	IF DB_ID(N'PizzeriaDB') IS NOT NULL
	BEGIN
	    PRINT 'La base PizzeriaDB ya esta conectada en la instancia.';
	END
	-- ----------------------------------------------------------------------------
	-- 2) Si no está conectada, se adjunta desde esta carpeta
	-- ----------------------------------------------------------------------------
	ELSE
	BEGIN
	    IF @ExisteMdf = 0
	    BEGIN
	        PRINT 'ERROR: No se encontro el archivo: ' + @Mdf;
	        PRINT 'Ejecute primero creaBaseDatosP.bat para crear la base de datos.';
	        ;THROW 50001, 'No existe pizzeriaDB.mdf en la carpeta del proyecto.', 1;
	    END
	
	    DECLARE @Sql NVARCHAR(MAX);
	
	    IF @ExisteLdf = 1
	    BEGIN
	        SET @Sql =
	            N'CREATE DATABASE [PizzeriaDB]
	              ON (FILENAME = N''' + @Mdf + N'''),
	                 (FILENAME = N''' + @Ldf + N''')
	              FOR ATTACH;';
	    END
	    ELSE
	    BEGIN
	        -- Sin archivo de log: SQL Server lo reconstruye
	        SET @Sql =
	            N'CREATE DATABASE [PizzeriaDB]
	              ON (FILENAME = N''' + @Mdf + N''')
	              FOR ATTACH_REBUILD_LOG;';
	    END
	
	    BEGIN TRY
	        EXEC sp_executesql @Sql;
	        PRINT 'Base de datos PizzeriaDB conectada correctamente.';
	    END TRY
	    BEGIN CATCH
	        PRINT 'No se pudo adjuntar con el log existente. Detalle: ' + ERROR_MESSAGE();
	
	        -- Segundo intento: reconstruir el log
	        BEGIN TRY
	            SET @Sql =
	                N'CREATE DATABASE [PizzeriaDB]
	                  ON (FILENAME = N''' + @Mdf + N''')
	                  FOR ATTACH_REBUILD_LOG;';
	            EXEC sp_executesql @Sql;
	            PRINT 'Base de datos PizzeriaDB conectada (log reconstruido).';
	        END TRY
	        BEGIN CATCH
	            PRINT 'ERROR: No se pudo conectar la base de datos.';
	            PRINT 'Si los archivos estan danados, ejecute creaBaseDatosP.bat.';
	            ;THROW;
	        END CATCH
	    END CATCH
	END
	
	-- Asegurar que la base quede disponible para varios usuarios
	IF DB_ID(N'PizzeriaDB') IS NOT NULL
	    ALTER DATABASE [PizzeriaDB] SET MULTI_USER;
	GO
	
	-- ----------------------------------------------------------------------------
	-- 3) Verificación de la conexión
	-- ----------------------------------------------------------------------------
	IF DB_ID(N'PizzeriaDB') IS NOT NULL
	    EXEC(N'
	        USE [PizzeriaDB];
	
	        SELECT
	            DB_NAME()        AS BaseDatos,
	            f.name           AS ArchivoLogico,
	            f.type_desc      AS Tipo,
	            f.physical_name  AS RutaFisica
	        FROM sys.master_files f
	        WHERE f.database_id = DB_ID();
	
	        SELECT
	            OBJECT_NAME(OBJECT_ID(N''dbo.Pedidos'')) AS Tabla,
	            COUNT(*) AS Columnas
	        FROM sys.columns
	        WHERE object_id = OBJECT_ID(N''dbo.Pedidos'');
	
	        SELECT COUNT(*) AS PedidosGuardados FROM dbo.Pedidos;
	    ');
	ELSE
	    PRINT 'La base PizzeriaDB no esta disponible.';
	GO

Archivo: creaBaseDatosPizzeria.sql

Contenido:
	-- ============================================================================
	-- CREACIÓN DE BASE DE DATOS - PIZZERÍA BELLA ITALIA
	-- ----------------------------------------------------------------------------
	-- Motor    : SQL Server / LocalDB
	-- Servidor : (localdb)\MSSQLLocalDB
	-- Base     : PizzeriaDB
	-- Archivos : pizzeriaDB.mdf y pizzeriaDB.ldf EN ESTA MISMA CARPETA
	--
	-- Alineado con la app (PedidoDAO.InsertarPedido / CalculadoraPedido), que
	-- inserta en dbo.Pedidos las columnas:
	--   Cliente, Telefono, TamanoNombre, PrecioBaseTamano, MasaNombre, RecargoMasa,
	--   QuesoExtra, Pepperoni, Champinones, Aceitunas, Tocino, EsDelivery,
	--   AplicaConvenioEstudiante, CostoIngredientes, SubtotalPizza, MontoDescuento,
	--   CostoDelivery, NetoAfecto, MontoIva, TotalPagar
	--
	-- Si la base ya existe pero sus archivos están en otra carpeta, se respalda
	-- (respaldo_pizzeriaDB.bak) y se vuelve a crear aquí.
	-- ============================================================================
	
	-- Ruta donde se crearán los archivos de datos.
	-- Si mueves el proyecto de carpeta, actualiza esta ruta y vuelve a ejecutar.
	DECLARE @DataDir NVARCHAR(400) = N'C:\desarrollo\Csoft\App_WinForms_Pizzeria_Bella_Italia_BD\Codigo_Funcional\BDpizzeria';
	DECLARE @Mdf     NVARCHAR(500) = @DataDir + N'\pizzeriaDB.mdf';
	DECLARE @Ldf     NVARCHAR(500) = @DataDir + N'\pizzeriaDB.ldf';
	DECLARE @Bak     NVARCHAR(500) = @DataDir + N'\respaldo_pizzeriaDB.bak';
	DECLARE @Actual  NVARCHAR(500);
	
	SELECT @Actual = physical_name
	FROM sys.master_files
	WHERE database_id = DB_ID(N'PizzeriaDB')
	  AND file_id = 1;
	
	-- ----------------------------------------------------------------------------
	-- 1) Si la base existe en otra ubicación: respaldar y recrear en esta carpeta
	-- ----------------------------------------------------------------------------
	IF DB_ID(N'PizzeriaDB') IS NOT NULL AND @Actual <> @Mdf
	BEGIN
	    PRINT 'La base PizzeriaDB existe en otra ubicación: ' + ISNULL(@Actual, '(desconocida)');
	    PRINT 'Se creará un respaldo y se recreará en la carpeta del proyecto...';
	
	    BACKUP DATABASE [PizzeriaDB]
	        TO DISK = @Bak
	        WITH INIT,
	             NAME = N'PizzeriaDB - respaldo antes de mover archivos';
	
	    ALTER DATABASE [PizzeriaDB] SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
	    DROP DATABASE [PizzeriaDB];
	END
	GO
	
	-- ----------------------------------------------------------------------------
	-- 2) Crear la base de datos con archivos en la carpeta del proyecto
	-- ----------------------------------------------------------------------------
	IF DB_ID(N'PizzeriaDB') IS NULL
	BEGIN
	    DECLARE @DataDir NVARCHAR(400) = N'C:\desarrollo\Csoft\App_WinForms_Pizzeria_Bella_Italia_BD\Codigo_Funcional\BDpizzeria';
	    DECLARE @Mdf     NVARCHAR(500) = @DataDir + N'\pizzeriaDB.mdf';
	    DECLARE @Ldf     NVARCHAR(500) = @DataDir + N'\pizzeriaDB.ldf';
	
	    DECLARE @SqlCrear NVARCHAR(MAX) =
	        N'CREATE DATABASE [PizzeriaDB]

	-- ============================================================================
	-- DESCONEXIÓN (DETACH) DE LA BASE DE DATOS - PIZZERÍA BELLA ITALIA
	-- ----------------------------------------------------------------------------
	-- Motor    : SQL Server / LocalDB
	-- Servidor : (localdb)\MSSQLLocalDB
	-- Base     : PizzeriaDB
	--
	-- Este script DESADJUNTA la base de la instancia, pero NO borra los archivos:
	--   pizzeriaDB.mdf y pizzeriaDB.ldf se mantienen en la carpeta del proyecto.
	--
	-- Después de ejecutarlo, la aplicación no podrá conectarse hasta que la base
	-- se vuelva a cargar con cargaBaseDatos.bat (o hasta que la app la adjunte
	-- automáticamente al guardar un pedido).
	-- ============================================================================
	
	SET NOCOUNT ON;
	
	IF DB_ID(N'PizzeriaDB') IS NULL
	BEGIN
	    PRINT 'La base PizzeriaDB no esta conectada. Nada que desconectar.';
	END
	ELSE
	BEGIN
	    BEGIN TRY
	        -- Cierra conexiones abiertas y deja la base en modo de un solo usuario
	        ALTER DATABASE [PizzeriaDB] SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
	
	        -- Desadjunta la base conservando los archivos .mdf y .ldf
	        EXEC master.dbo.sp_detach_db @dbname = N'PizzeriaDB';
	
	        PRINT 'Base de datos PizzeriaDB desconectada correctamente.';
	        PRINT 'Los archivos pizzeriaDB.mdf y pizzeriaDB.ldf se conservan en la carpeta.';
	    END TRY
	    BEGIN CATCH
	        PRINT 'ERROR al desconectar la base de datos: ' + ERROR_MESSAGE();
	        ;THROW;
	    END CATCH
	END
	GO
	
	-- ----------------------------------------------------------------------------
	-- Verificación: NULL = desconectada / numero = conectada
	-- ----------------------------------------------------------------------------
	SELECT DB_ID(N'PizzeriaDB') AS IdBaseConectada;
	GO

	using System.Collections.Generic;
	
	namespace PizzeriaBellaItalia.Dominio;
	
	// Reglas de negocio y cálculo de pedidos (desacopladas de la UI).
	public static class CalculadoraPedido
	{
	    // Opciones de tamaño: nombre -> precio base (CLP).
	    public static readonly IReadOnlyDictionary<string, int> Tamanos = new Dictionary<string, int>
	    {
	        { "Personal", 5000 },
	        { "Mediana", 8500 },
	        { "Familiar", 12000 }
	    };
	
	    // Opciones de masa: nombre -> recargo (CLP).
	    public static readonly IReadOnlyDictionary<string, int> Masas = new Dictionary<string, int>
	    {
	        { "Masa Tradicional", 0 },
	        { "Masa Delgada", 0 },
	        { "Borde de Queso", 1500 }
	    };
	
	    // Datos de entrada para el cálculo (sin dependencia de controles de UI).
	    public sealed class DatosPedido //sealed: indica que no se puede heredar
	    {
	        public string Cliente { get; set; } = "";
	        public string Telefono { get; set; } = "";
	        public string Tamano { get; set; } = "Mediana";
	        public string Masa { get; set; } = "Masa Tradicional";
	        public bool QuesoExtra { get; set; }
	        public bool Pepperoni { get; set; }
	        public bool Champinones { get; set; }
	        public bool Aceitunas { get; set; }
	        public bool Tocino { get; set; }
	        public bool EsDelivery { get; set; }
	        public bool AplicaConvenioEstudiante { get; set; }
	    }
	
	    // Aplica reglas y retorna un PedidoPizza con montos calculados.
	    //static significa que el miembro (o la clase) pertenece al tipo en sí, no a una instancia/objeto creado con new.
	    public static PedidoPizza Calcular(DatosPedido d)
	    {
	        int precioBase = Tamanos.TryGetValue(d.Tamano, out int pb) ? pb : Tamanos["Mediana"];
	        int recargoMasa = Masas.TryGetValue(d.Masa, out int rm) ? rm : 0;
	
	        int extras = (d.QuesoExtra ? 1 : 0) + (d.Pepperoni ? 1 : 0) +
	                     (d.Champinones ? 1 : 0) + (d.Aceitunas ? 1 : 0) + (d.Tocino ? 1 : 0);
	        int costoIng = extras * 800;
	
	        int subtotal = precioBase + recargoMasa + costoIng;
	        int descuento = d.AplicaConvenioEstudiante ? (int)(subtotal * 0.10) : 0;
	        int delivery = d.EsDelivery ? 2000 : 0;
	        int neto = subtotal - descuento + delivery;
	        int iva = (int)(neto * 0.19);
	        int total = neto + iva;
	
	        return new PedidoPizza //retorna un objeto de tipo PedidoPizza con los datos calculados
	        {
	            Cliente = d.Cliente,
	            Telefono = d.Telefono,
	            TamanoNombre = d.Tamano,
	            PrecioBaseTamano = precioBase,
	            MasaNombre = d.Masa,
	            RecargoMasa = recargoMasa,
	            QuesoExtra = d.QuesoExtra,
	            Pepperoni = d.Pepperoni,
	            Champinones = d.Champinones,
	            Aceitunas = d.Aceitunas,
	            Tocino = d.Tocino,
	            EsDelivery = d.EsDelivery,
	            AplicaConvenioEstudiante = d.AplicaConvenioEstudiante,
	            CostoIngredientes = costoIng,
	            SubtotalPizza = subtotal,
	            MontoDescuento = descuento,
	            CostoDelivery = delivery,
	            NetoAfecto = neto,
	            MontoIva = iva,
	            TotalPagar = total
	        };
	    }
	}

	FUNCIÓN: Clase de Entidad del Dominio. Representa un pedido individual,

	================================================================================
	
	using System;
	
	using System.Globalization;
	
	
	
	namespace PizzeriaBellaItalia.Dominio;  
	
	
	
	public class PedidoPizza
	
	{
	
	    // -------------------------------------------------------------------- PROPIEDADES / INPUTS
	
	    public string Cliente { get; set; } = string.Empty;
	
	    public string Telefono { get; set; } = string.Empty;
	
	
	
	    public string TamanoNombre { get; set; } = "Mediana";
	
	    public int PrecioBaseTamano { get; set; } = 8500;
	
	
	
	    public string MasaNombre { get; set; } = "Masa Tradicional";
	
	    public int RecargoMasa { get; set; } = 0;
	
	
	
	    // Adicionales
	
	    public bool QuesoExtra { get; set; } = false;
	
	    public bool Pepperoni { get; set; } = false;
	
	    public bool Champinones { get; set; } = false;
	
	    public bool Aceitunas { get; set; } = false;
	
	    public bool Tocino { get; set; } = false;
	
	
	
	    // Opciones de Entrega y Promoción
	
	    public bool EsDelivery { get; set; }
	
	    public bool AplicaConvenioEstudiante { get; set; }
	
	
	
	    // -------------------------------------------------------------------- CONSTANTES DE NEGOCIO
	
	    private const int PRECIO_INGREDIENTE_EXTRA = 800;
	
	    private const int RECARGO_DELIVERY = 2000;
	
	    private const double TASA_DESCUENTO = 0.10; // 10%
	
	    private const double TASA_IVA = 0.19;       // 19% IVA Chileno
	
	
	
	    // -------------------------------------------------------------------- MÉTODOS CÁLCULO
	
	    public int ContarIngredientesExtra()
	
	    {
	
	        int total = 0;
	
	        if (QuesoExtra) total++;
	
	        if (Pepperoni) total++;
	
	        if (Champinones) total++;
	
	        if (Aceitunas) total++;
	
	        if (Tocino) total++;
	
	        return total;
	
	    }
	
	
	
	    public int CalcularCostoIngredientes()
	
	    {
	
	        return ContarIngredientesExtra() * PRECIO_INGREDIENTE_EXTRA;
	
	    }
	
	
	
	    public int CalcularSubtotalPizza()
	
	    {
	
	        return PrecioBaseTamano + RecargoMasa + CalcularCostoIngredientes();
	
	    }
	
	
	
	    public int CalcularMontoDescuento()
	
	    {
	
	        return AplicaConvenioEstudiante ? (int)(CalcularSubtotalPizza() * TASA_DESCUENTO) : 0;
	
	    }
	
	
	
	    public int CalcularCostoDelivery()
	
	    {
	
	        return EsDelivery ? RECARGO_DELIVERY : 0;
	
	    }
	
	
	
	    public int CalcularNetoAfecto()
	
	    {
	
	        return (CalcularSubtotalPizza() - CalcularMontoDescuento()) + CalcularCostoDelivery();
	
	    }
	
	
	
	    public int CalcularMontoIva()
	
	    {
	
	        return (int)(CalcularNetoAfecto() * TASA_IVA);
	
	    }
	
	
	
	    public int CalcularTotalPagar()
	
	    {
	
	        return CalcularNetoAfecto() + CalcularMontoIva();
	
	    }
	
	
	
	    public override string ToString()
	
	    {
	
	        return $"{Cliente} | {TamanoNombre} ({MasaNombre}) -> Total: $ {CalcularTotalPagar():N0} CLP";
	
	    }
	
	}

	FLUJO DE LA APLICACION A PARTIR DE ACCIONES EN BOTONES
	Proyecto: Pizzeria Bella Italia (WinForms, 3 capas con DAO)
	Nota: UI (FormPedido) -> DAO (PedidoDAO) -> ConexionBD -> SQL Server (dbo.Pedidos). Los listados muestran Cliente, Telefono, TamanoNombre, TotalPagar (IdPedido se usa internamente y se oculta).
	
	1) Boton: Probar Conexion (btnProbarConexion)
	   - Click -> btnProbarConexion_Click.
	   - Llama ConexionBD.ProbarConexion() (intenta abrir/cerrar conexion).
	   - Muestra MessageBox con cadena de conexion y estado (exito o error).
	
	2) Boton: Calcular Total / Grabar (btnCalcular)
	   - Click -> BtnCalcular_Click.
	   - Valida que txtCliente no este vacio; si falla, avisa y detiene.
	   - ConstruirPedido(): lee controles, calcula montos (Subtotal, Descuento, Delivery, Neto, IVA, TotalPagar) y crea PedidoPizza.
	   - Muestra montos en lblSubtotalValor/lblDescuentoValor/lblDeliveryValor/lblIvaValor/lblTotalValor y habilita resumen.
	   - Pregunta confirmacion para grabar.
	     - Si: pedidoDao.InsertarPedido(p) -> INSERT en dbo.Pedidos; si ok muestra exito, LimpiarFormulario() y CargarPedidos() (refresca grilla).
	     - No: no persiste.
	
	3) Boton: Nuevo Pedido (btnLimpiar)
	   - Click -> BtnLimpiar_Click -> LimpiarFormulario().
	   - Limpia ID/cliente/telefono, restablece combos y opciones por defecto, reinicia montos/resumen y enfoca cliente.
	
	4) Boton: Actualizar Pedido (btnActualizarPedido)
	   - Click -> btnActualizarPedido_Click.
	   - Valida IdPedido (txtIdPedido) y cliente; si falla, avisa y detiene.
	   - ConstruirPedido() + asigna IdPedido.
	   - pedidoDao.ActualizarPedido(p) -> UPDATE dbo.Pedidos WHERE IdPedido=@IdPedido.
	   - Si ok: muestra exito y CargarPedidos(); si no afecta filas o hay error, muestra aviso/error.
	
	5) Boton: Eliminar Pedido (btnEliminarPedido)
	   - Click -> btnEliminarPedido_Click.
	   - Valida IdPedido; si falla, avisa y detiene.
	   - Solicita confirmacion (Si/No).
	     - Si: pedidoDao.EliminarPedido(id) -> DELETE FROM dbo.Pedidos WHERE IdPedido=@IdPedido.
	       - Si ok: muestra exito, LimpiarFormulario() y CargarPedidos().
	       - Si no: muestra aviso/error.
	
	6) Boton: Buscar pedido por cliente (btnBuscaPedidosXCliente)
	   - Click -> btnBuscaPedidosXCliente_Click.
	   - Lee filtro desde txtCliente (Trim).
	   - Si vacio: pedidoDao.ObtenerPedidosDataTable() -> SELECT ... ORDER BY IdPedido DESC.
	   - Si con texto: pedidoDao.BuscarPedidosPorCliente(filtro) -> SELECT ... WHERE Cliente LIKE @Filtro.
	   - Enlaza resultado a dgvPedidos (oculta IdPedido, muestra Cliente, Telefono, TamanoNombre, TotalPagar).
	
	7) Boton: Buscar pedido por ID (btnBuscarPedidoPorId)
	   - Click -> btnBuscarPedidoPorId_Click.
	   - Valida IdPedido en txtIdPedido; si invalido, avisa y detiene.
	   - pedidoDao.ObtenerPedidoPorId(id) -> SELECT completo WHERE IdPedido=@IdPedido.
	   - Muestra en dgvPedidos una fila con datos visibles (o vacia si no existe).
	   - Si no existe: informa "No se encontro".
	   - Si existe: llama vistaPedido(id) para cargar todos los detalles en el formulario.
	
	8) Boton: Todos los pedidos (btnTodosLosPedidos)
	   - Click -> btnTodosLosPedidos_Click -> CargarPedidos().
	   - pedidoDao.ObtenerPedidosDataTable() y refresca dgvPedidos.
	
	9) Boton: Salir (btnConfirmar)
	   - Click -> BtnSalir_Click.
	   - Solicita confirmacion; si acepta, Close() cierra el formulario (fin de la app).
	
	Acciones complementarias (no boton, relacionadas al flujo)
	- Al cargar formulario (Load): aplica tema/iconos, inicializa combos, CargarPedidos().
	- Click en fila de dgvPedidos (CellClick): obtiene IdPedido y ejecuta vistaPedido(id) -> carga en la UI todos los datos guardados (ID, cliente, configuracion, ingredientes, opciones y montos, incluido TotalPagar).
	- CargarPedidos/vistaPedido/operaciones CRUD usan ConexionBD.ObtenerConexion() para abrir conexion SQL y el DAO para ejecutar consultas parametrizadas.

	INSTITUTO PROFESIONAL VIRGINIO GÓMEZ

	    Caso Práctico de Aplicación: Pizzería Bella Italia (Persistencia en SQL Server Express)
	    🎯 RESULTADOS DE APRENDIZAJE EVALUADOS:
	
	        * D2.C2-RA3: Integra una aplicación de alto nivel con una base de datos relacional para la gestión persistente de información.
	        * D2.C1-RA3: Construye el módulo de acceso a datos aplicando principios de diseño y patrones de arquitectura desacoplada.
	
	        1. ESCENARIO DE NEGOCIO: PIZZERÍA BELLA ITALIA
	            En la Unidad II implementamos el registro de pedidos de pizza utilizando listas en memoria (List). 
	            Sin embargo, al cerrar el sistema, la información se pierde por completo. En esta sesión migraremos 
	            la persistencia hacia una base de datos relacional en SQL Server Express 
	            (.\SQLEXPRESS) utilizando el proveedor oficial ADO.NET (Microsoft.Data.SqlClient) en Visual Studio 2026.
	
	        2. PASO A PASO: CONFIGURACIÓN EN VISUAL STUDIO 2026
	            Abrir el Explorador de Servidores: 
	                  En Visual Studio 2026, presione Ctrl + Alt + S (o menú Ver → Explorador de Servidores).
	            Crear la Base de Datos: 
	                  Haga clic secundario en Conexiones de datos → Crear nueva base de datos de SQL Server...
	                    - Servidor: .\SQLEXPRESS
	                    - Nombre BD: PizzeriaDB
	
	            Crear Tabla Pedidos: 
	                Haga clic derecho en la conexión creada / Tablas → Nueva Tabla 
	                y genere la Tabla Pedidos según la siguiente especificación:
	
	                CREATE TABLE Pedidos (
	                Id INT IDENTITY(1,1) PRIMARY KEY,
	                Cliente NVARCHAR(100) NOT NULL,
	                Telefono NVARCHAR(20) NULL,
	                TamanoNombre NVARCHAR(50) NOT NULL,
	                TotalPagar INT NOT NULL,
	                FechaRegistro DATETIME DEFAULT GETDATE()
	                );
	
	            Instalar Paquete NuGet: 
	                Haga clic derecho en el proyecto → Administrar paquetes NuGet e instale 
	                Microsoft.Data.SqlClient.
	                //EN CONSOLA 
	                    Install-Package System.Data.SqlClient
	
	        COMPARATIVA: MODELO CONECTADO VS. MODELO DESCONECTADO

	================================================================================
						CONCEPTOS CLAROS DE ADO.NET
	================================================================================
	
	1. ¿QUÉ ES ADO.NET?
	================================================================================
	Es una librería de .NET que permite comunicarte con una base de datos SQL 
	usando código C#. Sin intermediarios (como Entity Framework).
	
	Aplicación C# ←→ ADO.NET ←→ SQL Server
	
	
	2. FLUJO BÁSICO DE GRABACIÓN
	================================================================================
	PASO 1: ABRIR CONEXIÓN
			↓
	PASO 2: CREAR COMANDO SQL
			↓
	PASO 3: AGREGAR PARÁMETROS (valores)
			↓
	PASO 4: EJECUTAR EL COMANDO
			↓
	PASO 5: CERRAR CONEXIÓN
	
	
	3. COMPONENTES PRINCIPALES
	================================================================================
	
	A) SqlConnection - La carretera
	----------------------------------
		SqlConnection conexion = new("Server=localhost;Database=PizzeriaDB;");
		//forma correcta 
		SqlConnection conexion = new(
			  "Server=localhost;Database=PizzeriaBellaItalia;Integrated Security=True;Encrypt=False;"
		);
	
		//con contraseña 
			SqlConnection conexion = new(
			"Server=localhost;Database=PizzeriaBellaItalia;User Id=sa;Password=tuContraseña;Encrypt=False;"
			);
	
		conexion.Open();   // Abrir la conexión
	
	¿Para qué? Establece el puente entre tu app y SQL Server.
	
	B) SqlCommand - El vehículo
	----------------------------------
		SqlCommand comando = new("INSERT INTO Pedidos VALUES (@Cliente, @Total)", 
		conexion);
	
	¿Para qué? Envía la orden SQL a ejecutar.
	
	
	C) SqlParameter - El pasajero
	----------------------------------
		comando.Parameters.AddWithValue("@Cliente", "Juan");
		comando.Parameters.AddWithValue("@Total", 25000);
	
	¿Para qué? Lleva los valores de manera segura (sin inyección SQL).
	
	
	4. INSERTAR DATOS - PASO A PASO
	================================================================================
	
	// 1. ABRIR CONEXIÓN
	using (SqlConnection conexion = new("Server=localhost;Database=PizzeriaBellaItalia;"))
	{
		conexion.Open();  // ← Abre el puente
	
		// 2. CREAR COMANDO SQL
		using (SqlCommand comando = new(
			"INSERT INTO Pedidos (Cliente, Telefono, TotalPagar) VALUES (@Cliente, @Telefono, @Total)",
			conexion))  // ← Asigna la conexión al comando
		{
			// 3. AGREGAR PARÁMETROS (valores)
			comando.Parameters.AddWithValue("@Cliente", pedido.Cliente);
			comando.Parameters.AddWithValue("@Telefono", pedido.Telefono);
			comando.Parameters.AddWithValue("@Total", pedido.CalcularTotalPagar());
	
			// 4. EJECUTAR
			int filasAfectadas = comando.ExecuteNonQuery();  // ← Ejecuta el INSERT
	
			// 5. VERIFICAR RESULTADO
			if (filasAfectadas > 0)
				MessageBox.Show("✅ Guardado");
			else
				MessageBox.Show("❌ No se grabó");
		}
		// ← La conexión se cierra automáticamente (using)
	}
	
	
	5. ¿POR QUÉ PARÁMETROS? (SEGURIDAD)
	================================================================================
	
	❌ MAL - Vulnerable a inyección SQL:
	-----------------------------------
		string query = "INSERT INTO Pedidos VALUES ('" + cliente + "', " + total + ")";
		// Si cliente = "'; DELETE FROM Pedidos; --"  → ¡Desastre!
	
	
	✅ BIEN - Seguro con parámetros:
	--------------------------------
		comando.Parameters.AddWithValue("@Cliente", cliente);
		// SQL interpreta como texto, no como código
	
	
	6. LECTURA DE DATOS
	================================================================================
	
	using (SqlConnection conexion = new("..."))
	{
		conexion.Open();
	
		using (SqlCommand comando = new("SELECT * FROM Pedidos", conexion))
		{
			using (SqlDataReader lector = comando.ExecuteReader())
			{
				while (lector.Read())
				{
					string cliente = lector["Cliente"].ToString();
					int total = (int)lector["TotalPagar"];
	
					Console.WriteLine($"{cliente} - ${total}");
				}
			}
		}
	}
	
	
	7. CICLO DE VIDA (USANDO USING)
	================================================================================
	
	using (SqlConnection conexion = new(...))
	{
		// ← COMIENZA (Open automático si es necesario)
	
		// Tu código aquí
	
	} // ← TERMINA (Dispose + Close automático)
	
	¿Para qué? Evita fugas de memoria. Cierra automáticamente.
	
	
	8. COMPARACIÓN: TRES FORMAS DE GRABAR
	================================================================================
	
	┌─────────────────┬──────────┬────────────┬──────────┐
	│ Método          │ Velocidad│ Complejidad│ Seguridad│
	├─────────────────┼──────────┼────────────┼──────────┤
	│ ADO.NET         │ ⚡ Rápido │ Medio      │ ✅ Alta  │
	│ Entity Framework│ Normal   │ Baja       │ ✅ Alta  │
	│ SQL directo     │ ⚡ Rápido │ Alto       │ ❌ Baja  │
	└─────────────────┴──────────┴────────────┴──────────┘
	
	
	9. ERRORES COMUNES
	================================================================================
	
	❌ Olvida parámetro
	-------------------
		comando.Parameters.AddWithValue("@Cliente", cliente);
		// Pero el SQL dice: (@Cliente, @Telefono)
		// → Error: Parámetro faltante
	
	
	❌ Olvida cerrar conexión
	-------------------
		SqlConnection conexion = new(...);
		conexion.Open();
		// ... código
		// No la cierra → Fuga de recursos
	
	
	❌ Tipo de dato incorrecto
	-------------------
		comando.Parameters.AddWithValue("@Total", "25000");  // String
		// Pero Total es INT → Error de conversión
	
	
	10. RESUMEN FINAL
	================================================================================
	
	Para GRABAR un pedido con ADO.NET:
	
	1. Abre conexión
	2. Escribe INSERT (con @parámetros)
	3. Llena los parámetros con AddWithValue()
	4. Ejecuta con ExecuteNonQuery()
	5. Cierra automáticamente (using)
	
	Todo protegido contra inyección SQL ✅
	
	
	================================================================================
								  NOTAS IMPORTANTES
	================================================================================
	
	• SqlConnection → Conecta con BD
	• SqlCommand → Ejecuta SQL
	• SqlParameter → Datos seguros (@nombre)
	• ExecuteNonQuery() → Para INSERT, UPDATE, DELETE
	• ExecuteReader() → Para SELECT (lectura)
	• using() → Cierra automáticamente

	FLUJO DE LA APLICACIÓN - Pizzería Bella Italia
	=============================================
	
	1) Inicio (FormPedido_Load)
	- Carga opciones de tamaño y masa desde CalculadoraPedido (Tamanos/Masas) y selecciona valores por defecto (Mediana, Masa Tradicional).
	- Deshabilita el resumen de montos.
	- Carga los pedidos desde la BD (PedidoDAO.ObtenerPedidosDataTable) y los muestra en la grilla.
	- La grilla muestra columnas visibles: Cliente, Teléfono, Tamaño, Total a Pagar; IdPedido queda oculto pero disponible internamente.
	
	2) Calcular Total / Grabar (btnCalcular)
	- Valida que exista nombre de cliente.
	- Construye datos desde la UI y calcula montos con CalculadoraPedido.Calcular (reglas: precio por tamaño, recargo de masa, $800 por ingrediente extra, 10% convenio estudiante sobre subtotal, $2000 delivery, 19% IVA).
	- Muestra subtotal, descuento, delivery, IVA y total en el resumen.
	- Pregunta si desea grabar el pedido:
	  - Si confirma: inserta en dbo.Pedidos mediante PedidoDAO.InsertarPedido, informa éxito, limpia el formulario y recarga la grilla.
	  - Si cancela o hay error: no inserta (muestra mensaje en caso de error).
	
	3) Buscar pedido por cliente (btnBuscaPedidosXCliente)
	- Toma el texto de cliente como filtro.
	- Si está vacío: lista todos los pedidos (ObtenerPedidosDataTable).
	- Si tiene valor: filtra con PedidoDAO.BuscarPedidosPorCliente (LIKE).
	- Actualiza la grilla manteniendo IdPedido oculto y títulos de columnas definidos.
	
	4) Buscar pedido por ID (btnBuscarPedidoPorId)
	- Valida que el ID sea un entero positivo.
	- Consulta PedidoDAO.ObtenerPedidoPorId(id).
	- Muestra el resultado en la grilla (IdPedido oculto, títulos definidos).
	- Si no existe: informa "No se encontró el pedido".
	- Si existe: carga todos los detalles en el formulario mediante vistaPedido(id) -> LlenaForm(p).
	
	5) Todos los pedidos (btnTodosLosPedidos)
	- Recarga el listado completo desde la BD y actualiza la grilla.
	
	6) Clic en fila de la grilla (dgvPedidos_CellClick)
	- Obtiene el IdPedido de la fila seleccionada (columna oculta).
	- Llama a vistaPedido(id) para recuperar el pedido completo y llenar el formulario con LlenaForm(p) (datos, configuración, ingredientes, montos y resumen).
	
	7) Actualizar pedido (btnActualizarPedido)
	- Valida que exista un ID válido y nombre de cliente.
	- Construye el pedido desde la UI (recalcula montos con CalculadoraPedido) y asigna el IdPedido indicado.
	- Ejecuta PedidoDAO.ActualizarPedido; informa resultado y recarga la grilla si fue exitoso.
	
	8) Eliminar pedido (btnEliminarPedido)
	- Valida que exista un ID válido.
	- Solicita confirmación.
	- Ejecuta PedidoDAO.EliminarPedido; si elimina, limpia el formulario y recarga la grilla.
	
	9) Probar conexión (btnProbarConexion)
	- Ejecuta ConexionBD.ProbarConexion y muestra la cadena de conexión y el estado (éxito/error).
	
	10) Nuevo Pedido / Limpiar (btnLimpiar)
	- Restablece campos, selecciones y montos a valores iniciales (Mediana, Masa Tradicional, retiro local, sin extras/convenio), deshabilita el resumen y enfoca cliente.
	
	11) Salir (btnConfirmar)
	- Solicita confirmación y cierra el formulario/aplicación.

	            {
	                MessageBox.Show("Ingrese un ID válido.", "Validación", MessageBoxButtons.OK, MessageBoxIcon.Warning);
	                txtIdPedido.Focus(); return;
	            }
	            try
	            {
	                var p = pedidoDao.ObtenerPedidoPorId(id); // Consulta el pedido completo por ID (o null si no existe).
	
	                // Crea una tabla temporal con las columnas para mostrar el resultado en la grilla.
	                var dt = new DataTable();
	                dt.Columns.Add("IdPedido", typeof(int));   // ID interno (se ocultará en la UI).
	                dt.Columns.Add("Cliente");                 // Dato visible.
	                dt.Columns.Add("Telefono");                // Dato visible.
	                dt.Columns.Add("TamanoNombre");            // Dato visible.
	                dt.Columns.Add("TotalPagar", typeof(int)); // Total final visible.
	
	                // Si se encontró el pedido, agrega una fila con sus datos.
	                if (p != null) dt.Rows.Add(p.IdPedido, p.Cliente, p.Telefono, p.TamanoNombre, p.TotalPagar);
	
	                dgvPedidos.DataSource = dt; // Enlaza la tabla a la grilla (con o sin filas).
	
	                // Oculta IdPedido y define los títulos visibles de las columnas.
	                var colId = dgvPedidos.Columns["IdPedido"];
	                if (colId != null) colId.Visible = false;
	                if (dgvPedidos.Columns["Cliente"] != null) dgvPedidos.Columns["Cliente"]!.HeaderText = "Cliente";
	                if (dgvPedidos.Columns["Telefono"] != null) dgvPedidos.Columns["Telefono"]!.HeaderText = "Teléfono";
	                if (dgvPedidos.Columns["TamanoNombre"] != null) dgvPedidos.Columns["TamanoNombre"]!.HeaderText = "Tamaño";
	                if (dgvPedidos.Columns["TotalPagar"] != null) dgvPedidos.Columns["TotalPagar"]!.HeaderText = "Total a Pagar";
	
	                // Informa si no existe; si existe, carga todos los detalles en el formulario.
	                if (p == null)
	                {
	                    MostrarEstado("No se encontró el pedido con el ID indicado.", false);
	                    MessageBox.Show("No se encontró el pedido.", "Búsqueda", MessageBoxButtons.OK, MessageBoxIcon.Information);
	                }
	                else
	                {
	                    MostrarEstado("Pedido encontrado y cargado en el formulario.", true);
	                    vistaPedido(p.IdPedido);
	                }
	            }
	            catch (Exception ex)
	            {
	                MostrarEstado("No se pudo buscar el pedido.", false);
	                MessageBox.Show("No se pudo buscar.\n" + ex.Message, "Base de datos", MessageBoxButtons.OK, MessageBoxIcon.Warning);

	# PizzeriaBellaItalia (WinForms + SQL Server LocalDB)
	
	Aplicación de escritorio en C# (Windows Forms, .NET 10) para la gestión de pedidos de la pizzería "Bella Italia", con persistencia en **SQL Server LocalDB** mediante **ADO.NET** (`Microsoft.Data.SqlClient`) y arquitectura en capas.
	
	## Estructura del proyecto
	
	- `Presentacion/`
	  - `FormPedido.cs`, `FormPedido.Designer.cs`: interfaz principal (ingreso, cálculo, grilla y acciones CRUD).
	- `Dominio/`
	  - `PedidoPizza.cs`: entidad/modelo que mapea los datos de un pedido (`dbo.Pedidos`).
	  - `PedidoDAO.cs`: acceso a datos (CRUD) con consultas SQL parametrizadas.
	  - `CalculadoraPedido.cs`: reglas de negocio/cálculo (tamaños, masas, extras, descuentos, delivery, IVA) desacopladas de la UI.
	  - `ConexionBD.cs`: cadena y obtención/prueba de conexión a la base de datos.
	- `BDpizzeria/`: scripts y utilitarios para crear/cargar/desconectar la base (`creaBaseDatosP.bat/.sql`, `cargaBaseDatos.bat/.sql`, `desconectaBase.bat/.sql`, archivos `.mdf/.ldf/.bak`, `cfg.txt`).
	- `flujo.txt`: descripción del flujo de acciones por botón.
	- `Program.cs`: punto de entrada de la aplicación.
	
	## Base de datos
	
	- **Motor/servidor**: `(localdb)\MSSQLLocalDB`
	- **Base de datos**: `PizzeriaDB`
	- **Tabla principal**: `dbo.Pedidos` (tabla única)
	
	Campos principales: `IdPedido` (IDENTITY, PK), datos de cliente (`Cliente`, `Telefono`), configuración (`TamanoNombre`, `PrecioBaseTamano`, `MasaNombre`, `RecargoMasa`), ingredientes (flags), entrega/promoción (`EsDelivery`, `AplicaConvenioEstudiante`), montos calculados (`CostoIngredientes`, `SubtotalPizza`, `MontoDescuento`, `CostoDelivery`, `NetoAfecto`, `MontoIva`, `TotalPagar`) y `FechaCreacion` (auditoría).
	
	> La cadena de conexión está definida en `Dominio/ConexionBD.cs`. Ajustarla si tu instancia/ruta de LocalDB es diferente.
	> Los scripts de `BDpizzeria` contienen rutas absolutas del proyecto; actualízalas si mueves la carpeta.
	
	## Funcionalidades (UI)
	
	- **Grilla de pedidos**: al iniciar se cargan los pedidos (`ObtenerPedidosDataTable`). Se muestran las columnas visibles `Cliente`, `Teléfono`, `Tamaño` y `Total a Pagar` (títulos definidos en la UI); `IdPedido` se mantiene oculto pero disponible para selección interna.
	- **Calcular / Grabar** (`btnCalcular`): valida datos mínimos, la UI arma los datos y delega el cálculo a `CalculadoraPedido.Calcular(...)` (tamaño/masa, extras, delivery, convenio, IVA), muestra el resumen y, tras confirmar, inserta el pedido (`PedidoDAO.InsertarPedido`).
	- **Buscar por cliente** (`btnBuscaPedidosXCliente`): filtra por nombre con `LIKE` (`BuscarPedidosPorCliente`).
	- **Buscar por ID** (`btnBuscarPedidoPorId`): obtiene un pedido por `IdPedido` (`ObtenerPedidoPorId`) y muestra su detalle.
	- **Todos los pedidos** (`btnTodosLosPedidos`): recarga el listado completo.
	- **Clic en fila**: al seleccionar una fila se obtiene el `IdPedido` y se cargan todos los detalles en el formulario (`vistaPedido` → `LlenaForm`).
	- **Actualizar pedido** (`btnActualizarPedido`): recalcula desde la UI y actualiza el pedido indicado por ID (`ActualizarPedido`).
	- **Eliminar pedido** (`btnEliminarPedido`): elimina previa confirmación (`EliminarPedido`).
	- **Probar conexión** (`btnProbarConexion`): verifica conectividad y muestra cadena/estado (`ConexionBD.ProbarConexion`).
	- **Nuevo pedido / Limpiar** (`btnLimpiar`) y **Salir** (`btnConfirmar`): restablecen el formulario o cierran la aplicación.
	- **Apariencia**: colores/estilos e íconos de botones definidos directamente en `FormPedido.Designer.cs`.
	
	## Arquitectura
	
	- **Presentación** (`Presentacion`): captura eventos, lee controles, coordina la UI y muestra resultados (`LlenaForm` carga datos/montos en pantalla).
	- **Reglas/Cálculo** (`Dominio/CalculadoraPedido.cs`): define opciones y calcula montos del pedido, desacoplado de controles WinForms.
	- **Datos/DAO** (`Dominio/PedidoDAO.cs`): ejecuta operaciones parametrizadas sobre `dbo.Pedidos` (INSERT, SELECT/listado, SELECT por cliente/ID, UPDATE, DELETE).
	- **Conexión** (`Dominio/ConexionBD.cs`): provee `SqlConnection` y utilitario de prueba.
	
	## Requisitos
	
	- Windows con soporte para .NET 10 y Windows Forms.
	- SQL Server LocalDB (`(localdb)\MSSQLLocalDB`) con la base `PizzeriaDB` creada/cargada (usar scripts en `BDpizzeria`).
	- Paquete NuGet: `Microsoft.Data.SqlClient`.
	
	## Notas
	
	- El total mostrado y persistido corresponde a `PedidoPizza.TotalPagar`.
	- `System.Data.SqlClient` puede aparecer comentado en el `.csproj`; el acceso a datos utiliza `Microsoft.Data.SqlClient`.
	- `BDpizzeria`: los scripts `.sql` y `.bat` usan rutas absolutas a esta carpeta; son correctos para la ruta del proyecto, pero deben actualizarse si se mueve la solución.
	- Ver `flujo.txt` para el detalle paso a paso de cada acción.
