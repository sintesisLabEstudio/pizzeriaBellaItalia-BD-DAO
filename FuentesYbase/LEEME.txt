FUENTES Y BASE DE DATOS — Pizzería Bella Italia
================================================

Esta carpeta contiene SOLO código fuente editable y los archivos de la base de datos.
No contiene binarios compilados (ni bin/, ni obj/).

CONTENIDO
---------
Program.cs                      Punto de entrada WinForms (Application.Run).
PizzeriaBellaItalia.csproj      Proyecto .NET 10 Windows Forms + Microsoft.Data.SqlClient 7.1.2.
PizzeriaBellaItalia.slnx        Solución (solo el proyecto principal).
Dominio/                        Clases editables:
                                  CalculadoraPedido.cs  (reglas de negocio y montos)
                                  Cliente.cs / PedidoPizza.cs  (entidades)
                                  ClienteDAO.cs / PedidoDAO.cs  (acceso a datos parametrizado)
                                  ConexionBD.cs  (cadena y conexión a LocalDB)
Presentacion/                   Formularios editables:
                                  FormPedido.cs / .Designer.cs
                                  FormClientes.cs / .Designer.cs
BDpizzeria/                     Base de datos con todos sus detalles:
                                  *.sql           creación, migración, carga, vaciado y desconexión
                                  *.bat           utilitarios para sqlcmd
                                  cfg.txt         configuración
                                  pizzeriaDB.mdf / .ldf    archivos físicos de la base
                                  respaldo_pizzeriaDB.bak  respaldo previo
                                  PizzeriaDB_Final_Completa.bak  respaldo final (con UQ aplicada)
                                  pruebaDao/      arnés de pruebas de los DAO (código fuente)
                                  imagenesDeApoyo/ capturas de referencia
flujo.txt                       Descripción paso a paso de cada botón.

Los documentos generados (DIAGRAMA_FLUJO.md con 9 diagramas Mermaid y
DIAGRAMA_FLUJO.txt en texto plano) se dejaron en la carpeta ../estudio/.
README.md                       Documentación general del proyecto.

REQUISITOS PARA COMPILAR
------------------------
- .NET 10 SDK con cargas de trabajo Windows Forms.
- Restaurar paquetes NuGet (Microsoft.Data.SqlClient 7.1.2).
- SQL Server LocalDB con la base PizzeriaDB creada/adjunta (scripts en BDpizzeria/).

NOTA
----
Los scripts .sql contienen rutas absolutas de la máquina de desarrollo original.
Si mueves esta carpeta, actualiza la variable @DataDir en
creaBaseDatosPizzeria.sql y cargaBaseDatos.sql antes de ejecutarlos.
