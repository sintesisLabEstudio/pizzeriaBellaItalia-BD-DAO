FLUJO DE LA APLICACION A PARTIR DE ACCIONES EN BOTONES
Proyecto: Pizzeria Bella Italia (WinForms, 3 capas con DAO)
Nota: UI (FormPedido) -> DAO (PedidoDAO) -> ConexionBD -> SQL Server (dbo.Pedidos). Los listados muestran Cliente, Telefono, TamanoNombre, TotalPagar (IdPedido se usa internamente y se oculta).

1) Boton: Probar Conexion (btnProbarConexion)
   - Click -> btnProbarConexion_Click.
   - Llama ConexionBD.ProbarConexion() (intenta abrir/cerrar conexion).
   - Muestra MessageBox con cadena de conexion y estado (exito o error).

2) Boton: Calcular Total / Grabar (btnCalcular)
   - Click -> BtnCalcular_Click.
   - Valida que txtCliente no este vacio; si falla, avisa y detiene.
   - ConstruirPedido(): lee controles, calcula montos (Subtotal, Descuento, Delivery, Neto, IVA, TotalPagar) y crea PedidoPizza.
   - Muestra montos en lblSubtotalValor/lblDescuentoValor/lblDeliveryValor/lblIvaValor/lblTotalValor y habilita resumen.
   - Pregunta confirmacion para grabar.
     - Si: pedidoDao.InsertarPedido(p) -> INSERT en dbo.Pedidos; si ok muestra exito, LimpiarFormulario() y CargarPedidos() (refresca grilla).
     - No: no persiste.

3) Boton: Nuevo Pedido (btnLimpiar)
   - Click -> BtnLimpiar_Click -> LimpiarFormulario().
   - Limpia ID/cliente/telefono, restablece combos y opciones por defecto, reinicia montos/resumen y enfoca cliente.

4) Boton: Actualizar Pedido (btnActualizarPedido)
   - Click -> btnActualizarPedido_Click.
   - Valida IdPedido (txtIdPedido) y cliente; si falla, avisa y detiene.
   - ConstruirPedido() + asigna IdPedido.
   - pedidoDao.ActualizarPedido(p) -> UPDATE dbo.Pedidos WHERE IdPedido=@IdPedido.
   - Si ok: muestra exito y CargarPedidos(); si no afecta filas o hay error, muestra aviso/error.

5) Boton: Eliminar Pedido (btnEliminarPedido)
   - Click -> btnEliminarPedido_Click.
   - Valida IdPedido; si falla, avisa y detiene.
   - Solicita confirmacion (Si/No).
     - Si: pedidoDao.EliminarPedido(id) -> DELETE FROM dbo.Pedidos WHERE IdPedido=@IdPedido.
       - Si ok: muestra exito, LimpiarFormulario() y CargarPedidos().
       - Si no: muestra aviso/error.

6) Boton: Buscar pedido por cliente (btnBuscaPedidosXCliente)
   - Click -> btnBuscaPedidosXCliente_Click.
   - Lee filtro desde txtCliente (Trim).
   - Si vacio: lblAyuda roja + MessageBox "Debe ingresar el nombre del cliente" + txtCliente.Focus(). NO consulta la BD.
   - Si con texto: pedidoDao.BuscarPedidosPorCliente(filtro) -> SELECT ... WHERE c.Cliente LIKE @Filtro.
   - Enlaza resultado a dgvPedidos (oculta IdPedido, muestra Cliente, Telefono, TamanoNombre, TotalPagar).

7) Boton: Buscar pedido por ID (btnBuscarPedidoPorId)
   - Click -> btnBuscarPedidoPorId_Click.
   - Valida IdPedido en txtIdPedido; si invalido, avisa y detiene.
   - pedidoDao.ObtenerPedidoPorId(id) -> SELECT completo WHERE IdPedido=@IdPedido.
   - Muestra en dgvPedidos una fila con datos visibles (o vacia si no existe).
   - Si no existe: informa "No se encontro".
   - Si existe: llama vistaPedido(id) para cargar todos los detalles en el formulario.

8) Boton: Todos los pedidos (btnTodosLosPedidos)
   - Click -> btnTodosLosPedidos_Click -> CargarPedidos().
   - pedidoDao.ObtenerPedidosDataTable() y refresca dgvPedidos.

9) Boton: Salir (btnConfirmar)
   - Click -> BtnSalir_Click.
   - Solicita confirmacion; si acepta, Close() cierra el formulario (fin de la app).

Acciones complementarias (no boton, relacionadas al flujo)
- Al cargar formulario (Load): aplica tema/iconos, inicializa combos, CargarPedidos().
- Click en fila de dgvPedidos (CellClick): obtiene IdPedido y ejecuta vistaPedido(id) -> carga en la UI todos los datos guardados (ID, cliente, configuracion, ingredientes, opciones y montos, incluido TotalPagar).
- CargarPedidos/vistaPedido/operaciones CRUD usan ConexionBD.ObtenerConexion() para abrir conexion SQL y el DAO para ejecutar consultas parametrizadas.
