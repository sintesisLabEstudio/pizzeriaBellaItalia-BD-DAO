        @echo off        oculta el eco de los comandos para que solo se vean los mensajes.
        setlocal/endlocal aísla las variables para que no afecten otras ventanas.
        set VAR=valor    define una variable; se usa como %VAR%.
        %~dp0            carpeta donde esta el .bat (barra final incluida).
        sqlcmd           utilidad de linea de comandos para SQL Server.
        -S               servidor; aqui siempre (localdb)\MSSQLLocalDB.
        -d               base de datos sobre la que se ejecuta la consulta.
        -Q "sql"         ejecuta una consulta escrita en la propia linea.
        -i "archivo.sql" ejecuta un archivo de script SQL.
        -b               hace que sqlcmd devuelva error si la instruccion falla.
        %ERRORLEVEL%     codigo de salida del ultimo comando: 0 = exito.
        if errorlevel 1 equivale a "si el ultimo comando fallo".
        goto :etiqueta   salta a una linea marcada con :etiqueta.
        choice /c SN     pregunta Si/No; errorlevel 1 = S, 2 = N.
        pause            espera a que el usuario presione una tecla.
        TRUNCATE         borra todas las filas y reinicia los contadores IDENTITY.

RUTA: C:\desarrollo\Csoft\pizzeriaBellaItalia-BD-DAO-v4B\Codigo_Funcional\BDpizzeria\comandos\BAT\01_creaBaseDatosP-01.bat
DESCRIPCION: Crea la base PizzeriaDB y sus dos tablas ejecutando el script SQL 01_Estructura_PizzeriaDB.sql. Version robusta.
CODIGO:
    @echo off
    setlocal EnableExtensions
    set "BASE_DIR=%~dp0"
    set "SQL_FILE=%BASE_DIR%01_Estructura_PizzeriaDB.sql"
    where sqlcmd >nul 2>&1
    if errorlevel 1 (
        echo ERROR: no se encontro sqlcmd en el PATH.
        echo Instale SQL Server Command Line Utilities y vuelva a intentar.
        goto :fin
    )
    if not exist "%SQL_FILE%" (
        echo ERROR: no se encontro el archivo 01_Estructura_PizzeriaDB.sql junto a este .bat.
        goto :fin
    )
    echo Creando la base PizzeriaDB y sus tablas si no existen...
    sqlcmd -S "(localdb)\MSSQLLocalDB" -b -i "%SQL_FILE%"
    if errorlevel 1 (
        echo Error al crear la base o las tablas.
    ) else (
        echo Base y tablas listas.
    )
    :fin
    endlocal
    pause
PASO A PASO:
    1. @echo off y setlocal EnableExtensions: ocultan el eco de comandos y activan extensiones de la consola.
    2. set BASE_DIR=%~dp0: guarda en una variable la carpeta donde esta este .bat (%~dp0 = unidad y ruta del archivo).
    3. set SQL_FILE=%BASE_DIR%01_Estructura_PizzeriaDB.sql: compone la ruta completa del script SQL que lo acompana.
    4. where sqlcmd: comprueba que la herramienta de linea de comandos de SQL Server este en el PATH; si no, avisa y salta a :fin.
    5. if not exist "%SQL_FILE%": verifica que el archivo SQL exista junto al .bat; si falta, avisa y termina.
    6. sqlcmd -S "(localdb)\MSSQLLocalDB" -b -i "%SQL_FILE%": ejecuta el script contra LocalDB. -b hace que sqlcmd devuelva error si la instruccion falla.
    7. if errorlevel 1 ... else ...: informa si la base y las tablas quedaron listas o si hubo error.
    8. :fin, endlocal y pause: etiqueta de salida comun, restaura el entorno y espera a que el usuario presione una tecla.

DESCRIPCION: Borra todos los clientes y pedidos y reinicia los contadores IDENTITY, con confirmacion y transaccion atomica. Version robusta.
CODIGO:
    @echo off
    setlocal EnableExtensions
    where sqlcmd >nul 2>&1
    if errorlevel 1 (
        echo ERROR: no se encontro sqlcmd en el PATH.
        echo Instale SQL Server Command Line Utilities y vuelva a intentar.
        goto :fin
    )
    choice /c SN /m "Esto BORRA todos los clientes y pedidos. Desea continuar"
    if errorlevel 2 (
        echo Operacion cancelada.
        goto :fin
    )
    echo Vaciando tablas y reiniciando contadores IDENTITY...
    sqlcmd -S "(localdb)\MSSQLLocalDB" -d PizzeriaDB -b -Q "SET XACT_ABORT ON; BEGIN TRANSACTION; ALTER TABLE dbo.Pedidos DROP CONSTRAINT FK_Pedidos_Clientes; TRUNCATE TABLE dbo.Pedidos; TRUNCATE TABLE dbo.Clientes; ALTER TABLE dbo.Pedidos ADD CONSTRAINT FK_Pedidos_Clientes FOREIGN KEY (IdCliente) REFERENCES dbo.Clientes (IdCliente); COMMIT TRANSACTION;"
    if errorlevel 1 (
        echo Error al vaciar la base. No se aplico ningun cambio.
    ) else (
        echo Base vaciada y contadores reiniciados.
    )
    :fin
    endlocal
    pause
PASO A PASO:
    1. Inicializacion y where sqlcmd: misma preparacion que los scripts anteriores.
    2. choice /c SN: pide confirmacion porque la operacion es destructiva; con N se cancela.
    3. SET XACT_ABORT ON y BEGIN TRANSACTION: aseguran que, si algo falla, se revierta todo junto.
    4. ALTER TABLE ... DROP CONSTRAINT FK_Pedidos_Clientes: quita temporalmente la llave foranea para poder vaciar ambas tablas.
    5. TRUNCATE TABLE Pedidos y Clientes: borra todas las filas y reinicia los IDENTITY (a diferencia de DELETE).
    6. ALTER TABLE ... ADD CONSTRAINT: recrea la llave foranea para dejar la integridad intacta.
    7. COMMIT TRANSACTION: confirma el conjunto completo de cambios.
    8. if errorlevel 1 ... else ...: avisa si no se aplico ningun cambio o si la base quedo vaciada.
    9. :fin, endlocal, pause: cierre estandar.
