2. CAPA DE DOMINIO (Dominio/)
-------------------------------------------------------------------------------
PedidoPizza.cs   Entidad que mapea dbo.Pedidos.
  IdPedido, IdCliente (FK), Cliente, Telefono,
  TamanoNombre, PrecioBaseTamano, MasaNombre, RecargoMasa,
  QuesoExtra, Pepperoni, Champinones, Aceitunas, Tocino,
  EsDelivery, AplicaConvenioEstudiante,
  CostoIngredientes, SubtotalPizza, MontoDescuento, CostoDelivery,
  NetoAfecto, MontoIva, TotalPagar.

Cliente.cs       Entidad que mapea dbo.Clientes: IdCliente, Nombre, Telefono.

CalculadoraPedido.cs   Reglas de negocio (static, sin controles WinForms).
  Tamanos  : Personal 5000 / Mediana 8500 / Familiar 12000
  Masas    : Tradicional 0 / Delgada 0 / Borde de Queso 1500
  DatosPedido: clase anidada con los valores de entrada de la UI.
  Calcular(datos) -> PedidoPizza:
      extras   = 800 * (# de ingredientes activos)
      subtotal = precioBase + recargoMasa + extras
      descuento= 10% del subtotal si convenio estudiante
      delivery = 2000 si es delivery
      neto     = subtotal - descuento + delivery
      iva      = 19% del neto
      total    = neto + iva

ConexionBD.cs    Cadena unica y fabrica de conexiones.
  CadenaConexion : Server=(localdb)\MSSQLLocalDB;Database=PizzeriaDB;
                   Integrated Security=True;TrustServerCertificate=True;
  ObtenerConexion(): abre y devuelve SqlConnection (el llamador la cierra).
  ProbarConexion(): bool, captura SqlException.

PedidoDAO.cs     CRUD de dbo.Pedidos (consultas parametrizadas).
  InsertarPedido(p)            INSERT + SCOPE_IDENTITY, usa transaccion.
  ObtenerPedidosDataTable()    SELECT con INNER JOIN Clientes, ORDER BY IdPedido DESC.
  BuscarPedidosPorCliente(f)   WHERE c.Cliente LIKE @Filtro ("%" + f + "%").
  ObtenerPedidoPorId(id)       SELECT completo -> PedidoPizza o null.
  ActualizarPedido(p)          UPDATE por IdPedido, usa transaccion.
  EliminarPedido(id)           DELETE por IdPedido.
  ResolverIdCliente(n,t)       reutiliza el IdCliente o crea el cliente.
  CargarParametros(cmd,p)      carga los 21 parametros del INSERT/UPDATE.

ClienteDAO.cs    CRUD de dbo.Clientes (12 metodos).
  ObtenerClientesDataTable / BuscarPorNombreYTelefono / insertarCliente /
  InsertarClienteConTransaccion / ObtenerOCrearIdCliente / ActualizarCliente /
  EliminarCliente / validaClienteSinPedidos / BuscarClientesDataTable /
  testInsertarCliente / ObtenerPedidosPorCliente / ObtenerClientePorId /
  EsClienteDuplicado(ex) -> detecta SqlException 2601/2627.

3. CAPA DE PRESENTACION (Presentacion/)
-------------------------------------------------------------------------------
FormPedido.cs    Pantalla principal de pedidos (partial con .Designer.cs).
  Carga combos desde CalculadoraPedido.Tamanos/Masas.
  Grilla: oculta IdPedido e IdCliente; muestra Cliente, Telefono, Tamano y
          Total a Pagar.
  Calculo_Changed: recalcula en vivo al cambiar combos/checks/radios, salvo
          mientras cargandoFormulario = true o el resumen esta deshabilitado.
  BtnCalcular_Click: valida cliente, calcula, muestra resumen, confirma e inserta.
  btnBuscaPedidosXCliente_Click: con filtro VACIO muestra validacion (no lista todo).
  btnBuscarPedidoPorId_Click: busca por ID, muestra 1 fila y carga el detalle.
  btnTodosLosPedidos_Click / dgvPedidos_CellClick -> vistaPedido -> LlenaForm.
  btnActualizarPedido_Click / btnEliminarPedido_Click: UPDATE / DELETE con
          validacion de ID y confirmacion para borrar.
  btnProbarConexion_Click: muestra cadena y estado.
  btnEditaClientes_Click: abre FormClientes en modal (ShowDialog).
  CargarClienteDesdeSeleccion(n,t): recibe el cliente elegido en FormClientes.
  MostrarEstado / ConfigurarAyuda: lblAyuda con color y tooltips al hover.

FormClientes.cs  ABM de clientes y seleccion para el pedido.
  btnGrabar_Click: inserta o actualiza segun idClienteSeleccionado; valida
          duplicados por (Nombre, Telefono) antes de grabar y tambien por
          SqlException 2601/2627.
  btnElimina_Click: bloquea la eliminacion si validaClienteSinPedidos() = false.
  btnBuscar_Click: filtra por nombre o telefono con LIKE.
  dgvClientes_CellDoubleClick: carga la fila en modo edicion.
  btnSelecciona_Click: inyecta cliente en FormPedido y cierra esta ventana.
