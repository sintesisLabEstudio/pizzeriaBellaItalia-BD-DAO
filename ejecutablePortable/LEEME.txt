========================================================
Pizzeria Bella Italia - VERSION PORTABLE (Windows x64)
========================================================

CONTENIDO DE ESTA CARPETA
  PizzeriaBellaItalia.exe              Aplicacion. Es autocontenida: NO requiere
                                       tener .NET instalado en el equipo.
  Microsoft.Data.SqlClient.SNI.dll     Libreria nativa del proveedor SQL.
                                       Debe permanecer junto al .exe.
  INSTALAR_BD.bat                      Crea la base PizzeriaDB en LocalDB (una vez).
  BD/creaBaseDatosPizzeria.sql         Script de creacion con ruta parametrizada.
  BD/PizzeriaDB_Final_Completa.bak     Respaldo con los datos y la restriccion
                                       UQ_Clientes_Cliente_Telefono aplicada.

REQUISITOS EN EL EQUIPO DESTINO
  - Windows x64.
  - SQL Server LocalDB (instancia (localdb)\MSSQLLocalDB).
  - sqlcmd.exe (viene con las herramientas de cliente de SQL Server).

USO
  1) Ejecutar INSTALAR_BD.bat como usuario con permisos sobre LocalDB.
     Esto crea PizzeriaDB con todas sus tablas y el UNIQUE de clientes.
  2) Ejecutar PizzeriaBellaItalia.exe.

DATOS
  La base creada por el script arranca VACIA (sin clientes ni pedidos).
  Si desea recuperar los datos de desarrollo, restaure
  BD/PizzeriaDB_Final_Completa.bak desde SQL Server Management Studio usando
  la opcion WITH MOVE para ubicar .mdf/.ldf dentro de la carpeta BD.

CONEXION
  Server=(localdb)\MSSQLLocalDB;Database=PizzeriaDB;Integrated Security=True;
  La cadena esta compilada en la aplicacion (Dominio/ConexionBD.cs en las fuentes).

NOTA
  La carpeta FuentesYbase contiene el codigo editable y la base con todos
  sus detalles. Los diagramas y documentos generados estan en la carpeta estudio/.
