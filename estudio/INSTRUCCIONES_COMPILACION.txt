================================================================================
COMO COMPILAR PIZZERIA BELLA ITALIA EN VISUAL STUDIO
================================================================================

1. REQUISITOS PREVIOS
--------------------------------------------------------------------------------
  - Visual Studio 2022 reciente (17.13 o superior) o Visual Studio mas nuevo.
    Nota: la solucion es .slnx. Si tu VS no abre ese formato, no hay problema:
    usa Archivo > Abrir > Proyecto/Solucion y selecciona directamente
    PizzeriaBellaItalia.csproj.
  - Carga de trabajo "Desarrollo de escritorio .NET" (.NET desktop development),
    que incluye Windows Forms.
  - SDK de .NET 10 instalado (el proyecto apunta a net10.0-windows).
  - Opcional: SQL Server LocalDB con sqlcmd para probar la base de datos.

2. ABRIR EL PROYECTO
--------------------------------------------------------------------------------
  Opcion A: desde la carpeta principal del repositorio:
    Archivo > Abrir > Proyecto/Solucion > PizzeriaBellaItalia.slnx
    (o PizzeriaBellaItalia.csproj si tu VS no soporta .slnx).

  Opcion B: desde la carpeta FuentesYbase (solo codigo editable):
    Archivo > Abrir > Proyecto/Solucion > FuentesYbase\PizzeriaBellaItalia.csproj
    Esa carpeta contiene Program.cs, Dominio\, Presentacion\ y BDpizzeria\.

3. RESTAURAR PAQUETES NUGET
--------------------------------------------------------------------------------
  - En el Explorador de soluciones, clic derecho sobre la solucion >
    "Restaurar paquetes NuGet".
  - Tambien se restaura automaticamente al compilar.
  - Paquete requerido: Microsoft.Data.SqlClient 7.1.2 (nuget.org).

4. COMPILAR
--------------------------------------------------------------------------------
  - En la barra de herramientas elige:
      Configuracion de solucion: Release
      Plataforma de solucion:    x64  (o Any CPU)
  - Compilacion > Compilar solucion   (Ctrl+Shift+B).
  - La ventana de salida debe terminar con:
      "Compilacion correcta. 0 Error(es). 0 Advertencia(s)."
  - El ejecutable queda en:
      bin\Release\net10.0-windows\win-x64\PizzeriaBellaItalia.exe
    (o en bin\Release\net10.0-windows\ si elegiste Any CPU).

5. EJECUTAR
--------------------------------------------------------------------------------
  - Depurar > Iniciar depuracion (F5), o Depurar > Iniciar sin depurar (Ctrl+F5).
  - Antes de ejecutar, la base de datos debe existir (ver punto 6).

6. PREPARAR LA BASE DE DATOS (una vez por equipo)
--------------------------------------------------------------------------------
  Opcion rapida:
    Abrir una terminal CMD en la carpeta ejecutablePortable y ejecutar:
        INSTALAR_BD.bat
    Ese script crea PizzeriaDB en (localdb)\MSSQLLocalDB.

  Opcion manual con SQL Server Management Studio:
    1) Conectarse a (localdb)\MSSQLLocalDB.
    2) Ejecutar BDpizzeria\creaBaseDatosPizzeria.sql
       (crea Clientes, Pedidos, la FK y UQ_Clientes_Cliente_Telefono).
    3) Si la base ya existia, ejecutar actualizaBaseDatosClientes.sql
       (migracion idempotente).
  - IMPORTANTE: los .sql originales tienen rutas absolutas de la maquina de
    desarrollo. Si mueves la carpeta, cambia la variable @DataDir al inicio
    de creaBaseDatosPizzeria.sql y cargaBaseDatos.sql.
  - Si LocalDB esta detenido:  sqllocaldb start MSSQLLocalDB

7. PUBLICAR EL PORTABLE (igual que la carpeta ejecutablePortable)
--------------------------------------------------------------------------------
  Desde Visual Studio:
    Clic derecho en el proyecto > Publicar... > Nuevo perfil > Carpeta
    y configurar:
      Destino           : ejecutablePortable
      Runtime de destino: win-x64
      Modo de entrega    : Autocontenido (self-contained)
      Archivo unico      : activado (Produce single file)
      Simbolos de depuracion: desactivados
    Clic en Publicar.

  Equivalente por linea de comandos:
    dotnet publish PizzeriaBellaItalia.csproj -c Release -r win-x64 ^
      --self-contained true ^
      -p:PublishSingleFile=true -p:DebugType=none ^
      -p:EnableCompressionInSingleFile=true ^
      -o ejecutablePortable

8. PROBLEMAS FRECUENTES
--------------------------------------------------------------------------------
  - "No se encuentra el SDK de .NET 10" -> instalar .NET 10 SDK.
  - "No se pudo restaurar Microsoft.Data.SqlClient" -> verificar conexion a
    nuget.org y volver a Restaurar paquetes NuGet.
  - MSB3577 (dos recursos con el mismo nombre) -> no dejar copias de
    Presentacion\*.resx dentro de la carpeta del proyecto. El .csproj ya
    excluye FuentesYbase\** y ejecutablePortable\** para evitarlo.
  - Al iniciar, la grilla muestra error de conexion -> revisar que LocalDB
    este activo y que la base PizzeriaDB exista (punto 6).
  - Mensaje "Cliente duplicado" -> es la restriccion
    UQ_Clientes_Cliente_Telefono funcionando; edite el cliente existente.
